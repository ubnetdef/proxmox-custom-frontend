UBnetDef Custom Frontend Deployment Tool (Proxmox VE)
=========
Custom features included:
- No subscription popups or panels
- Custom Branding
- Cleaned up UI
- Customized tree view

How to deploy the custom frontend
=========
- Download the repository's 'Configuration.js' and 'Deployment.sh' file
- Run the 'Deployment.sh' file (root account is required in order to use)
